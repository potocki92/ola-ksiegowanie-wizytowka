# ola-ksiegowanie-wizytowka

Marketing website for Aleksandra Potocka — Księgowość (accounting services).
Built with [Astro](https://astro.build), TypeScript, and Tailwind CSS.

See [AGENTS.md](./AGENTS.md) for project conventions and [ARCHITECTURE.md](./ARCHITECTURE.md)
for how the codebase is organized.

## Development

```bash
npm install
npm run dev       # start the dev server at http://localhost:4321
npm run check     # type-check .astro/.ts files
npm run build     # production build to dist/
npm run preview   # preview the production build locally
```
